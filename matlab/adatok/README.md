## Használat

A MATLAB Current Folder legyen a repo \`matlab\` mappája. A \`setup.m\` az \`adatok\` mappát automatikusan felveszi a MATLAB útvonalra.

A többi eredeti mérési állomány (például teglatest1.mat, rad_bomlas.mat, rezges5.mat, hang_jelek1.mat és WAV-fájlok) a felhasználó által átadott teljes archívumban és a külön rendezett adat-ZIP-ben található. A repo jelenleg nem tartalmazza az összes nagy mérési fájlt.

A mérési adatfájlok nem azonosak a tanári PDF-ekkel és harmadik fél kézikönyveivel. Eredetüket külön jelölöm; az adatok publikálása nem jelent felhatalmazást a kapcsolódó egyetemi vagy gyártói kiadványok további újraterjesztésére.
